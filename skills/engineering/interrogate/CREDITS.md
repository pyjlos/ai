# Credits

This skill adapts Lauren Tan's [`interrogate`](https://github.com/cursor/plugins/blob/main/pstack/skills/interrogate/SKILL.md) skill from Cursor's `pstack` plugin, MIT-licensed. The structure (state intent, spawn adversarial reviewers in parallel, weight findings two or more reviewers raise independently as the strongest signal, sort into Act On / Consider / Noted / Dismissed) is reproduced closely. The "one reviewer per configured model" mechanic is replaced: `pstack`'s version depends on `~/.cursor/rules/pstack-models.mdc`, a Cursor-specific per-model routing config this repo has no equivalent of. Here, reviewer diversity comes from distinct adversarial angles given to parallel subagents instead, mirroring how this repo's own `code-review` skill already fans a review out in parallel. `interrogate` does not depend on `pstack` as a plugin, so the content is copied in and adapted rather than pointed at.
